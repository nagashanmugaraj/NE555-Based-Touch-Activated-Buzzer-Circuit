
# NE555-Based Touch-Activated Buzzer Circuit

## Overview
Designed an NE555 timer-based buzzer circuit using KiCad EDA. This project covers schematic design, PCB layout, component placement, copper track routing, and 3D PCB visualization.

## Components Used
- NE555 Timer IC
- 1 kΩ Resistor
- 10 kΩ Resistor
- 1 nF Capacitor
- 100 µF Electrolytic Capacitor
- Power Supply Connector
- Input Connector
- Buzzer Connector

## Software Used
- KiCad EDA
- KiCad Schematic Editor
- KiCad PCB Editor
- KiCad 3D Viewer
